随手记笔记本 · Windows 版

【怎么用】
1. 把「随手记笔记本.exe」放到你喜欢的位置（比如桌面、或 D 盘的文件夹里）
2. 双击打开即可，会弹出一个没有地址栏的独立窗口
3. 想固定到任务栏：窗口打开后，右键任务栏里的图标 →「固定到任务栏」

【数据存在哪】
%LOCALAPPDATA%\IvyNoteApp
（在文件资源管理器地址栏粘贴这个路径就能进去）

这是一个独立的浏览器资料目录，和你平时用的 Edge/Chrome 互不影响，
所以这里的笔记不会和浏览器里的混在一起。

【容量】
笔记存在 WebView 的本地数据库里，能用几百 MB 到几 GB，正常使用远到不了上限。
想要多设备同步，进 ⚙ → 云同步设置，用账号登录即可。

【想换电脑 / 留后路】
⚙ → 导出全部笔记（备份），会弹系统保存框，可以选任意文件夹。
换电脑后在 ⚙ → 导入 Markdown / HTML / 备份 里选那个 .json 文件，
笔记和笔记本分类都会回来。

【常见问题】
· 双击没反应：可能被杀毒软件拦了，允许一下即可（这个程序只做一件事：
  调用系统自带的 Edge 打开你的笔记，不联网做别的）。
· 窗口里显示「暂时连不上服务器」：检查网络，点「重新加载」。
· 想用真正的系统通知：Windows 版走的是 Edge 窗口模式，
  待办提醒会在页面内提示；想要系统级提醒，可以用「提醒与日历」里的日历订阅。

【卸载】
删掉「随手记笔记本.exe」即可；如果想把数据也清掉，再删掉
%LOCALAPPDATA%\IvyNoteApp 这个文件夹（删了就没了，先导出备份）。
